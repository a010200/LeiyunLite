# 雷云lite v1.0 · UI R3

本轮按要求暂停旋转校正工作。旋转相关源文件未修改；本版仍不能用它改变系统光标轨迹。更新源保持未配置。

## 启动与回退

先按根 README 构建源码，在托盘右键菜单中退出正在运行的旧版，再运行构建输出的 LeiyunLite.Desktop.exe。要求 Windows 10/11 x64、.NET Framework 4.8。程序未签名，不要为此关闭系统防护。

执行 `LeiyunLite.Desktop.exe --demo` 只做安全预览：模拟设备，不监听键鼠、不发送输入、不保存设置。不能用预览模式测试录制。

R3 使用原有用户配置目录及宏 XML 格式，不自动改写宏。此前 R2、首轮预览及 v1.0 的 EXE 和压缩包由维护者另行留存，当前源码不包含这些旧包。更换 EXE 位置后，如需开机运行本版，在设置中重新启用“开机自启动”，确认指向本版。

## 托盘

- 左键按下即请求打开型号/电量卡片，不再等待系统双击判定，也不等待设备读取。先呈现最近一次读数及时间，刷新按钮仍可主动读取。
- 单击、双击和连续左键点击都只使用同一个卡片，不通过双击打开主窗口。
- 打开主窗口请使用卡片中的“打开主界面”或右键菜单。右键保留设置、宏、暂停绑定、停止及退出等操作。
- 左右弹层互斥，失焦或 Esc 关闭；连续托盘点击引起的暂时失焦在消息处理后核对，避免误销毁已经重新激活的卡片。
- 卡片入场位移/轻回弹约 170 ms，透明度约 140 ms。此动画不会延迟菜单操作。

## 下拉菜单

所有新版下拉控件统一使用轻量弹性展开：约 200 ms 的 5 DIP 位移与轻微回弹、110 ms 淡入，箭头约 150 ms 转向。不缩放文字、不逐行弹跳、不动画列表高度。

靠近屏幕底部向上展开时反向位移。长列表正常滚动；快速重开替换动画，关闭立即生效；减少动画或系统关闭动画时直接呈现。

实现采用独立控件实例的变换，在实际 Popup 呈现后启动，避免 WPF 模板共享状态和弹层初始化时序问题。参考：[微软 ComboBox 弹层生命周期文档](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.combobox.ondropdownopened?view=windowsdesktop-9.0)。

## 宏页面

顶部三层结构：

1. 标题在左；保存状态和“保存并应用”在右。
2. “我的宏 / 按键绑定”使用文字标签与绿色下划线。
3. 宏选择、新建、更多在左；录制、试运行、停止在右。

工具按钮统一 36 DIP，按组分隔。窄窗口将新建操作收到“更多”，避免换行堆叠；动作属性仍使用窄屏抽屉。绑定页不显示无关的录制工具。空动作列表提供添加/录制引导，空宏不能试运行，无执行任务时停止按钮禁用。

## 基础键鼠录制

1. 打开“录制”，选择新建宏（默认）或追加当前宏。
2. 选择实际间隔、固定间隔或无间隔。
3. 点击开始，3 秒内切换到目标应用。倒计时期间尚不采集输入。
4. 录制键盘按下/松开、组合键、鼠标左右中键与 X1/X2、竖向滚轮上下。
5. 点击停止或按 Ctrl + Shift + F12。结果进入未保存草稿，可编辑并绑定到按键/滚轮，确认后再保存应用。

录制期间暂停宏绑定并停止既有宏；退出录制恢复用户原先的暂停设置。在托盘修改暂停状态也会被保留。停止快捷键及其未使用的 Ctrl/Shift 尾部动作从结果中排除；软件自身控件、重复按下及合成输入被排除。鼠标点击按目标窗口排除，避免点击“停止”时把该点击收进宏。

停止时只在草稿补齐尚未松开的输入，不向系统发送释放操作。取消不会改变原宏。最多 10 分钟、每宏共 500 步，包括延迟和预留的松开动作；即将超限时自动停止。挂钩回调只做有界入队，工作线程转换动作，不在回调中写文件或操作界面。

### 范围与隐私

- 仅用户明确开启的本地录制会采集输入；不上传，不作为后台键盘日志运行。
- 请勿录制密码或敏感内容；本版无法可靠识别所有应用的密码框。
- 不记录指针移动/坐标。鼠标点击回放时作用于当时指针所在位置。
- 记录按键而非输入法最终文字；文字输入可使用已有的手动“文本”动作。键盘布局变化可能改变回放结果。
- 不自动推断循环、启动程序或运行命令。
- 管理员窗口、安全桌面、游戏原始输入/反作弊环境不保证录制或回放兼容。系统安全组合键不支持模拟。
- 开始前已按住的键不视为录制动作；开始时应先松开按键。软件窗口本身不用于录制目标。

## 验证记录（2026-09-27）

- 12 组桌面/核心测试通过：原 8 组与 4 组录制测试。
- 录制覆盖实际/固定/无间隔、重复与合成输入过滤、键鼠顺序、停止手势排除、容量及预留释放、工作队列、原生回调解码到录制、录制到播放引擎、暂停恢复与不自动保存。
- WPF 测试覆盖倒计时、停止、结果进入草稿、取消追加、窄窗口不重叠、菜单动画/复开/关闭/减少动画/底部向上展开。
- 托盘测试经 NotifyIcon 的左键事件入口验证：双次按下保持同一弹窗、主窗口保持隐藏；左右菜单互斥、暂时失焦后重激活不销毁卡片。
- 26 组旧版回归测试通过。需要前台输入和临时注册表键的两项在正常桌面权限下验证；未执行真实鼠标写入。
- 界面截图由测试窗口渲染，不是设备实拍。还需要用户验收物理托盘点击手感、多显示器/混合缩放，以及日常目标应用的实际录制体验；未声称已覆盖这些环境。

## 构建

源码入口 LeiyunLite.Desktop.csproj。无须安装新 SDK，可用已有 .NET Framework 编译器：

    powershell -NoProfile -ExecutionPolicy Bypass -File build-desktop.ps1 -Test -Regression

默认产物在 bin/DesktopR3。测试不能向真实设备写入；不要添加 -Hardware，除非明确要进行实机只读测试。
