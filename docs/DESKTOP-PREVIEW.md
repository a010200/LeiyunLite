# 雷云lite v1.0 · Fluent Preview

日期：2026-09-27。此版本不是全部需求已完成的正式版；旧版 `LeiyunLite.exe` 与原便携包保持不变。

## 已实现

- WPF 单窗口：设备、宏与绑定、左下设置、设置下方自动更新。Windows 10/11 x64，.NET Framework 4.8。
- 自绘 #040404 标题栏和侧栏，#141414 内容底色，#44D62C 强调色。保留系统拖动、缩放、最大化行为。
- 180–200 ms 页面淡入与小幅位移、100 ms 按钮按压反馈；快速导航替换当前动画、停止隐藏页动画；支持减少动画与系统动画开关。
- 宏列表、动作序列、9 类动作编辑、按键/鼠标/滚轮绑定都在同一窗口，编辑使用右侧抽屉；页面切换保留草稿，退出时提示未保存修改。仍由已测试的原宏执行器处理停止、取消、输入释放和紧急停止键。
- 设置迁移：语言（系统/简中/English）、减少动画、关闭到托盘、开机启动当前版本、低电量提醒、刷新间隔、托盘样式、DPI 浮窗。部分底层错误仍使用原来的中文提示。启用当前版本自启会替换旧版同名启动项；未操作开关时保留旧项。
- DPI 滑条每 50 DPI 轻吸附；跟随数值框可输入整数。松手或 Enter 提交，Esc 撤销输入；只改当前档位并保留其他档位，读回验证之后才显示成功。
- 根据设备 PID 和连接类型选择回报率，不给未知接收器套用 8 kHz 档位。SE 普通接收器列出 125 / 500 / 1000 Hz；HyperPolling 通用接收器的配对设备识别未实现，不开放猜测写入。
- 修正 SE 普通接收器协议：旧程序使用的扩展命令 `00/C0` 在本机返回“不支持”，实际应使用旧版 `00/85` 查询、`00/05` 设置。真实读取已得到 500 Hz。
- 检查响应对应的指令，避免其他后台软件的 DPI 回复被误当回报率。对回报率 getter 限定重试；setter 不盲目重试。新版写入还验证 PID、事务号与校验和。
- 新图标：绿色圆底 + 原创 L/闪电负形，与官方标志区分；源代码绘制、透明背景、多尺寸 ICO，已内嵌新版。

## 未完成 / 明确限制

### 旋转校正尚不能影响系统指针

模型可实时旋转，角度可键入，测量向导能对至少 10 条一致长直线估算建议角度；**这不等于真实旋转功能已实现**。应用按钮禁用，模型角度不是鼠标读回状态。

计算使用二维旋转矩阵，保留位移长度而不是强制 Y=0；左右来回划线按无向主轴估计，过滤短线、明显曲线和离群角度。采样来自系统指针而非 Raw Input；结果是测量建议，不是硬件校准认证。若已有校正，计算“当前已应用角度 − 观测残余角度”，避免重复补偿。官方 UI 的角度符号和设备协议还需要外部画图对照确认。

用户已确认官方雷云对此鼠标有效。本地只读研究找到官方 `getMouseSensorRotationAngle` / `setMouseSensorRotationAngle` 包装接口，以及一条驱动 IOCTL 实现线索，但尚不能证明本机 SE 走同一路径。未加载或分发其私有 DLL，未安装驱动，未注入进程，未发送猜测指令。按 Confidence Check 的验证要求，该写入通路保持未开放。

下一步需要受控的官方软件角度变化前后协议对照，确认设备端/驱动端、角度单位和符号、写入与读回，再在外部画图程序验证同一方向运动的效果。若需要安装 USB 采集驱动，应先获得明确同意并限定采集目标；本次没有进行此操作。

### 更新源未配置

没有用户自有发布仓库和签名公钥，更新页面不会发送网络请求。检查按钮说明缺少配置；本版**没有启用下载、安装、后台更新或回滚执行器**，不能把界面入口说成已完成在线升级。不会使用原作者 Release 覆盖本修改版。后续接入需同时实现签名清单、哈希验证、原子替换、配置保护、停止宏与输入释放、失败回滚。

### 实机写入仍需验收

此轮没有改变真实 DPI/回报率；保留用户 800 DPI、500 Hz。新写入路径已经模拟设备验证，真实数值读取正常，但“设置成功读回”和“有效输入回报率实测”是两种验证，不混为一谈。首次测试请退出旧版和官方雷云的设备管理后台，避免共享 HID 回复互相干扰。不要同时运行两个驱动控制工具。

宏是 Windows 全局软件宏，程序需驻留后台；不能单独区分来自哪一只鼠标，也不写入板载宏。对管理员程序、游戏反作弊或屏蔽模拟输入的软件不保证可用。不要为此关闭系统安全保护。

## 运行与构建

安全看界面：`LeiyunLite.Desktop.exe --demo`。模拟 98% 电量、800 DPI、1000 Hz，仅是演示数据；不查询/写入硬件，不安装输入钩子，不执行宏，不保存用户配置。

正常使用：先从托盘退出旧版，再运行 `LeiyunLite.Desktop.exe`。新版和旧版使用同一互斥锁防止双开。读取原宏和通用设置；桌面新增设置保存在 `%LOCALAPPDATA%/LeiyunLite/desktop.xml`，宏仍使用同目录的 `macros.xml`。

构建：

```powershell
.\build-desktop.ps1
.\build-desktop.ps1 -Test
.\build-desktop.ps1 -Test -Regression -Hardware
```

编译器使用 Windows 现有 .NET Framework 工具，不安装全局 SDK。打开源码请用 `LeiyunLite.Desktop.csproj`；原 `RazerBatteryTray.csproj` 仍是旧 WinForms 入口。MSBuild 构建也通过；本机缺少 4.8 Targeting Pack，因此出现 MSB3644 警告并使用已安装的框架程序集，跨机器正式发行应安装对应 Targeting Pack 再构建。开发没有引入 UXTU 源码、硬件调谐服务或专有雷蛇 DLL。

## 验证结果与边界

- 新增桌面测试：8 组通过。覆盖 PID 能力边界、90/91 字节写入与其他档位保留、ACK 无效果时失败、错误 PID/指令、回报率读回、旋转矩阵、反向划线/离群值/已应用角度、配置隔离、全部页面与动作抽屉渲染、实际编辑提交、滚轮绑定、草稿保留、未保存退出、100 次快速导航与隐藏动画清理。
- 原功能回归：27 组通过，含宏执行、取消释放、参数校验、原生钩子、Unicode SendInput、协议、配置、托盘、OSD 和实机只读生命周期。
- 实机：Viper V3 Pro SE，PID 00DF，91 字节报告，电量 94%，800 DPI，500 Hz，1 个 DPI 档位。数值为测试时读到的状态，之后可正常变化。
- 隔离输入窗口/临时注册表测试首次被沙箱限制，获准重跑后通过；没有跳过或伪造通过。
- 截图由 WPF 实际控件树渲染，不是概念图；默认截图使用演示数据。尚未人工验收全部窗口缩放、多显示器 DPI、实际滚轮手感和真实硬件写入。
- 数学测试不能代替旋转硬件控制验证；本轮未完成实机旋转和在线升级验收。
