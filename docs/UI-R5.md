# R5 使用与验证说明

本地版本：1.0.0-r5。未提交、推送或发布到 GitHub。R3/R4 软件和源码快照不覆盖。

## 使用变化

- DPI 滑条仍为100–8000；位置 p 对应 100 + 7900 × p²，再按50 DPI取整。方向键±50、PageUp/PageDown±100，Home/End到端点。输入框仍允许设备能力范围内数值；高于8000的读数显示真实数值，滑块位于右端，不会自动写回。
- 默认录制范围改为中央录制区。明确开始、倒计时3秒，然后用真实键鼠操作；并非虚拟键盘。动作每100ms以内按UI调度更新，停止后生成未保存草稿。
- 失去区域焦点时暂停并补齐已按下按键的释放，恢复后不计入暂停时间。切换到其他应用不会在区域模式下继续录入；外部录制需要在开始前主动选择。
- 开始/停止/取消/工具栏不录入；原有自身窗口绑定绕过不变。Ctrl+Shift+F12紧急停止。实际间隔/固定间隔/无间隔、500步/10分钟上限、注入输入过滤等保留。
- 不记录鼠标移动、绝对坐标、输入法最终文本，不自动保存，不上传。录制时不要输入密码。

## 身份和协议分离

目录含113条OpenRazer鼠标相关PID及SE有线/无线、Mouse Dock Pro、已知键盘排除，共117项，并非117款经过实测的鼠标。来源固定：
[OpenRazer mouse PID header](https://github.com/openrazer/openrazer/blob/b9614b9bd41629f657e3f1fdea1c25a74c0dc695/driver/razermouse_driver.h)。
只整理标识事实，未引入其驱动实现。补充项来自用户提供的只读评审，证据等级在目录内保留。

- 从HIDD_ATTRIBUTES取得VID/PID/设备版本，而非在路径上匹配字符串；HIDP_CAPS校验用途与Feature Report长度。
- ContainerId优先分组，缺失时用序列号，再缺失则保守使用接口路径；实例键还包含VID/PID/版本。降级分组不宣称跨端口或有线/无线合并。
- 产品字符串只保留作诊断，不覆盖目录型号。通用HyperPolling/Dock显示接收器本身，不猜配对鼠标。
- 身份目录和协议配置独立；新PID不会获得任何控制命令。保留的00C0/00C1/00DE/00DF仅为R4实验性兼容路径，**不代表已完成实机写入验收**。
- 当前协议仅接受90/91字节、匹配事务ID/命令/数据长度/CRC及成功状态的回包，校验档位数量、编号及DPI。取消猜测事务ID轮询。
- 选择具体实例及接口；高速DPI读和写入不再随枚举顺序切换设备。界面提交携带实例键，过期请求拒绝。
- 区分“仅身份”“接口存在但遥测无响应”“可读遥测”“同实例近期缓存”。0%是合法电量；没有读数则未知，不填50%/800/1000。
- 缓存保存于旧缓存根下的Devices/哈希实例键子项；旧全局缓存不迁移到未知实例。目录版本变更、设备键不符、缓存超过5分钟都不能作为新遥测。缓存不是休眠状态的硬件证明。
- 本次不增加多鼠标切换器，不保证所有Razer键盘、耳机、底座都纳入身份表；未收录项只显示未知，不冒认为鼠标，不控制。

参考：[HIDD_ATTRIBUTES](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/hidsdi/ns-hidsdi-_hidd_attributes)、[HIDP_CAPS](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/hidpi/ns-hidpi-_hidp_caps)、[ContainerId](https://learn.microsoft.com/en-us/windows-hardware/drivers/install/devpkey-device-containerid)。

## 验证与边界

- 构建：Framework脚本与MSBuild Release；输出bin/DesktopR5和bin/VSCodeR5。
- 自动测试：22组桌面/核心 +26组旧功能回归。包括曲线全量50DPI往返/单调/端点、录制过滤/暂停/实时列表、报文故障、同PID多实例/多接口、缓存过期/隔离及过期写入拒绝。
- 正常桌面测试使用隔离的测试窗口、模拟设备与随机测试注册表子项；不写真实鼠标。沙箱注册表权限不足的失败记录保留，正常桌面测试通过后才定版。
- 录制区截图为受控测试事件；有原生Hook解码和隔离窗口输入测试，但这不等于用户物理鼠标各键已逐一验收。
- SE实机只读：1532:00DF，版本0100，共10个HID接口，仅1个91字节鼠标集合可探测；读取83%/800 DPI/500 Hz。不记录原始设备路径或序列号。检查工具Tools/InspectIdentity.cs不调用设置命令，也不保存用户缓存。
- 更新校验仍用原R4实现；当前比较基线升至r5。没有重新做线上下载验收、安装或发布。
- 旋转硬件不变，仍仅预览；无新驱动安装，无猜测旋转指令。Win11、混合缩放、多设备实机、目标游戏及高权限窗口不保证兼容。

## 手工验收建议

退出旧版后运行R5普通版（不是--demo）。在宏页开始区域录制，依次左/右/中键、侧键、滚轮上/下及普通键盘组合；实时列表应出现，点击停止不应额外记录控制按钮。失焦/恢复、取消、新建/追加分别试一次。先检查草稿再保存，在无风险的目标窗口试运行。
