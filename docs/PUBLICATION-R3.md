# R3 公开源码验证记录

日期：2026-09-27。版本：v1.0 UI R3，信息版本 `1.0.0-r3`。

本次在已有 R3 基础上整理首次公开源码；不表示增加了旋转硬件控制、在线更新或新的设备兼容性。

## 验证方式

- 将实际待发布 Git 索引导出为独立目录；不复制 `.local-tools`、已有 `bin/obj` 或开发者编辑器配置。
- 在干净目录执行 `Tools/Build-VSCode.ps1 -Configuration Release`，MSBuild 构建通过。
- 再执行 `build-desktop.ps1 -Test -Regression -OutputDirectory bin/Verification`，Framework 编译器构建通过，12 组桌面/核心与 26 组回归测试通过。
- 测试未加 `-Hardware`，不读取或写入真实鼠标。设备写入断言使用模拟设备；真实设备参数写入仍需独立实测。
- README 由独立读者检查了版本、构建入口、宏录制与保存、功能限制及署名；本地 Markdown 链接与公开文件清单经检查。
- 发布文件及 7 个上游提交进行了常见令牌、私钥前缀扫描，未发现匹配。这是有限的模式检查，不是完整安全审计，也不能保证没有未知类型的敏感信息或漏洞。

## 发布内容

只公开源码、必要图标、3 张 R3 演示截图、构建配置和文档。保留原 MIT 版权通知及上游 Git 历史。原有二进制、旧宣传截图从当前树移出，历史提交仍可追溯；不要把历史二进制当作本版下载。

本次不创建 GitHub Release 或上传预编译附件。源码及对应软件包由维护者在本地独立留档；软件包包含编译结果、许可证、使用说明、测试结果与 SHA256。不同编译器/构建时间产生的 EXE 不保证逐字节一致。

## 仍需验收

Windows 11、物理多显示器/混合缩放、真实目标应用录制回放、不同鼠标/接收器及各档位实际写入。程序尚未签名，旋转校正只预览，自动更新未配置。
