# 雷云lite v1.1.0

v1.1.0 将此前本地 R5 正式编号发布。本次仅统一版本信息和发布材料，不额外改变 R5 的设备、宏或界面功能。

## 下载与升级

在 [GitHub Release](https://github.com/a010200/LeiyunLite/releases/tag/v1.1.0) 下载 `LeiyunLite-v1.1.0-win-x64.zip`，不要把 Source code 当成已编译软件。Windows 10/11 x64，.NET Framework 4.8；本机验证环境为 Windows 10。

1. 用附件 `SHA256SUMS.txt` 核对 ZIP。
2. 从托盘退出旧版，解压到新目录，运行 `LeiyunLite.Desktop.exe`。
3. 标题和“设置 → 关于”均应显示 v1.1.0。
4. 宏、偏好位置不变；不要删除原配置。更换 EXE 路径后如需自启动，请重新启用“开机自启动”。

程序未签名，不需要关闭系统安全防护。更新功能是手动检查、下载、校验，不自动安装或重启。

## 相比公开 R3 的主要改进

- 解绑立即撤销并保存，停止原宏，不会被未保存的宏草稿重新激活。
- 宏库 + 鼠标按键示意绑定，支持拖拽或点击分配。
- 中央区域录制实际键鼠并实时显示；失焦暂停，恢复后排除空闲时间。外部录制需主动选择，停止后保留为未保存草稿。
- DPI 滑条100–8000，非线性映射扩展低 DPI 段，按50 DPI吸附；手动输入仍遵循设备上限。
- 身份目录、协议能力分开，正式 HID 属性识别、严格回包验证、实例与接口固定、缓存隔离；未知读数不再填假默认值。
- 托盘卡片显示电量、DPI和回报率；接入本仓库的更新下载与校验。

## 本次版本统一

程序集/文件版本1.1.0.0，产品版本、界面标题、关于页、更新比较基线1.1.0。统一常量位于 `Properties/AssemblyInfo.cs`。
构建输出 `bin/Desktop1.1.0` 或 `bin/VSCode1.1.0`。解决方案文件仍为 `LeiyunLite.R3.sln`，只为兼容编辑器入口，不代表运行R3。

## 验证和限制

发布前运行23组桌面/核心与26组旧功能回归，Framework和MSBuild Release两条构建路径验证，并检查仅含公开文件的干净源码能否构建。版本测试覆盖程序集/文件/更新信息一致、R5升级到1.1.0、同版本不再提供升级。

原R5的SE只读实测为83%电量、800 DPI、500 Hz；本次改名不代表新增硬件验收。身份表117项不等于117款设备全面可控；新增身份项只识别，原四PID控制仍属实验性兼容。宏为软件级，退出即停，不写板载内存；实体输入、游戏、管理员窗口及多屏混合缩放需各自测试。

旋转仍仅预览，不会校正其他应用的光标。无灯效/固件升级、自动安装器或全型号保证。录制时不要输入密码。更详细的实现记录见 [R5说明](UI-R5.md)，其中“未发布”等措辞仅描述当时的本地版本。
