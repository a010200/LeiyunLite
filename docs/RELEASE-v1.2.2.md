# 雷云lite v1.2.2

本轮修复开机自启动窗口和宏播放时序，并为“按住右键后中键宏无反应”增加可见诊断。发布包在独立目录生成，不替换日常安装或历史版本。

## 下载

- 安装版：`LeiyunLite-v1.2.2-Setup-x64.exe`，当前用户安装，支持签名更新。
- 便携版：`LeiyunLite-v1.2.2-win-x64.zip`，完整解压后运行 `LeiyunLite.Desktop.exe`。
- 更新附件：`LeiyunLite-v1.2.2-update-x64.zip` 和 `LeiyunLite-v1.2.2-update.json`，供安装版更新器使用。
- 校验：`SHA256SUMS.txt`。项目更新签名不等于 Windows 发布者代码签名。

## 修改

- 静默自启动不再调用会显示主窗口的 `Application.Run(window)`；先建立不可见 HWND，再初始化托盘、设备监控和更新服务。
- 自动迁移旧 HKCU Run 命令；登录后六分钟内遇到已注册但缺少参数的旧启动项时，沿用静默启动偏好。
- 删除按住重复每轮固定 25ms 等待。显式延迟改为高分辨率 waitable timer，并按 `Stopwatch` 绝对截止时间调度，减少累计漂移。
- 完全无延迟的重复宏仍自动等待 1ms，避免无限忙循环占满 CPU。
- 输入钩子跟踪物理右键状态。右键按住时触发中键，宏页会持续显示钩子接收、绑定启动及 80ms 内成功提交给 Windows 的输入数量；诊断仅在内存中保存。

## 限制与待继续验证

1. 重新登录 Windows，确认只出现托盘图标，任务栏和桌面不闪现黑色主窗口。
2. 使用现有连点宏比较 v1.2.1、v1.2.2 和官方驱动的实际速度。
3. 游戏内按住右键再按中键；若诊断显示已收到触发且已向 Windows 提交输入，但游戏仍无动作，则边界位于游戏对用户态 `SendInput` 的处理，不能把它误报为绑定失效。

`SendInput` 受目标程序权限、Raw Input 和游戏输入策略影响。本版不加入虚拟 HID、内核驱动或反作弊绕过。
