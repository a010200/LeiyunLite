# 雷云lite v1.0 验证报告

日期：2026-09-27。原版基线：`47fd9b1`。上次纯拆分报告另存为 `REFACTOR-VERIFICATION.md`，其中的 EXE、颜色与历史实机读数不代表本次结果。

## 结果

- 编译通过；正式入口 `LeiyunLite.exe`，名称雷云lite，文件版本 1.0.0.0。
- 28 组检查通过、0 失败：9 组宏检查、17 组原有逻辑检查、1 组基线对照、1 组实机只读检查。
- 48 组 HID 请求与原版逐字节一致；150 组托盘图像尺寸保持一致。颜色按要求变化，不再要求像素与原版一致。
- 主窗口、宏编辑器、动作/绑定对话框、三个 OSD 均已渲染检查；主题常量为 `#44D62C` 和 `#141414`。

## 宏检查

1. 模拟输出检查键盘、鼠标按钮、滚轮、中文文本、启动、命令、嵌套循环与调用宏的顺序。
2. 取消延迟、执行异常和释放执行器后释放按住的键/按钮；并发启动被拒绝。
3. 嵌套空循环消耗预算，超限终止。
4. 拒绝非法范围、未配对循环、缺失目标、递归/过深调用、重复绑定、滚轮按住模式及占用紧急停止键。
5. 路由检查一次、按住、开关、长按不重复触发、成对拦截、注入过滤、禁用、窗口保护和紧急停止。
6. 隔离 XML 检查中文往返、原子替换、备份、损坏文件不被覆盖、DTD 拒绝。
7. 编辑器创建/复制/重命名/保存回读、对话框渲染、主窗口入口复用及释放；未自动操作每个模态按钮。
8. 实际安装原生钩子，SendInput 向独立前台文本框输入中文并验证收到；模拟输入未进入触发器。仅启动无副作用的 `cmd.exe /d /c exit 0` 检查命令启动通路。
9. 构造原生回调数据，检查修饰键、按下/松开、五个标准鼠标按钮、半格滚轮拦截/累计、反向多格和注入标记。这是回调解码测试，并非用户物理按键逐一实测。

普通宏执行测试中的启动/命令目标由模拟输出器记录，不执行任意外部程序。

## 原有功能与实机

原有测试覆盖 90/91 字节 HID、事务 ID 回退、无响应/异常响应、休眠/唤醒/断连、缓存隔离、DPI/回报率模拟写入、设置与自启隔离注册表、DPI 监控、窗口状态与释放、OSD 非激活与鼠标穿透标志。

本轮检测到 **Razer Viper V3 Pro SE**，91 字节报告。设备休眠/无遥测响应，快速 DPI 查询未成功。日志的 50%、800 DPI、1000 Hz 是无历史缓存时的原版兜底，不是真实读取值。本轮确认了设备识别、休眠分支与原生生命周期，不能声称验证了清醒状态电量或真实 DPI/回报率修改。

未改变真实鼠标参数或用户实际开机自启项。注册表测试使用随机独立子项，结束清除；宏测试文件保留在 `bin/Tests/artifacts/`。

## 验证边界

多型号兼容、物理按键逐一实测、不同缩放/多显示器完整交互、小时级稳定性、游戏/反作弊/高权限目标、真实文件关联/网址启动，以及真实设备参数写入，均未验证。

首轮受限会话无法让测试文本框获得前台，也不能正常写测试注册表；在获准桌面环境重跑后通过，没有跳过这两项断言。

```cmd
build.bat -Test -Hardware

```
