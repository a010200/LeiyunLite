# 雷云lite v1.2.7（2026-10-04）

- 统一托盘菜单图标，与主界面保持一致。
- 右侧面板支持收起把手、点击遮罩和 Esc 关闭。
- 减少按键处理的内存分配，普通模式不再执行详细输入诊断。
- 改善 GitHub 限流时的更新检查与恢复提示。

本轮在 v1.2.6 基线上整合输入小修、更新限流退避和公共 UI 组件改进，维护者授权定版并发布 v1.2.7。普通输入不再构造物理键身份字符串；录制配对使用相同值类型键，配置格式不变。详细诊断仍可用 `--diagnostics` 显式开启。

更新检查识别可靠的 403/429 限流信号，保存独立 UTC 退避状态；普通自动冷却允许手动检查，已知限流窗口内显示预计恢复时间。GitHub 源、分页大小、更新签名、大小/哈希、版本防降级、安装和回滚保护保持。

托盘使用固定提交的 Microsoft Fluent System Icons / Regular 20px。统一 Drawer 删除标题区关闭字符，增加左边界收起把手；所有关闭入口仍执行统一清理与焦点恢复，子控件 Escape 和录制状态优先，内容宽度保持原响应式语义。

未改变硬件写入白名单、TID=0x1F、90/91 字节报文、协议/CRC、设备实例隔离、Hook 生命周期或 BindingRouter gate/Stop 顺序。1ms 防突发调度、迟到模拟按下拦截、最终抬起与 WhileHeld 行为保留。

安装版使用 `LeiyunLite-v1.2.7-Setup-x64.exe`；便携版完整解压 `LeiyunLite-v1.2.7-win-x64.zip` 后运行主程序。升级前保存草稿、停止宏并从托盘正常退出旧实例。打包和发布不会替换维护者的日常安装。

本轮没有新增游戏、Win11 Snap/Win+Z 或硬件参数写入验收。真实物理鼠标 A/B 只有一对数据，不足以确认所有场景或更高回报率；不宣称游戏/FPS 鼠标延迟被彻底解决。托盘菜单自动化与失焦处理器验证通过，原生通知区右键和真实桌面失焦切换仍待手动验收。详细本地证据见 `test-artifacts/release-v1.2.7.md`，发布结果与软件包校验以该报告为准。
