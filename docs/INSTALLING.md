# 安装与更新（当前版本 v1.3.0）

当前安装包为 [v1.3.0](https://github.com/a010200/LeiyunLite/releases/tag/v1.3.0)，同时提供安装版、便携版、项目签名更新包/清单与 SHA256 校验文件。升级前先从托盘正常退出旧便携版或其他同时运行的雷云 lite。

Windows 10/11 x64，需 .NET Framework 4.8。安装程序默认仅为当前用户安装，不自动安装系统组件、不重启电脑。首次从便携版迁移，请先从托盘退出旧版，再运行 Setup-x64.exe。安装版支持一键升级；旧 v1.1.0 仍需手动运行一次安装程序。

程序位于 `%LOCALAPPDATA%\Programs\LeiyunLite`，宏与偏好仍在 `%LOCALAPPDATA%\LeiyunLite`，旧注册表设置位置保持兼容。快捷方式和自启动指向固定启动入口；不要直接启动 versions 中的旧 EXE。卸载默认保留个人数据，交互卸载时另行确认才能清除。

更新设置分为自动检查、自动下载、空闲自动安装。后两项默认关闭；自动安装要求至少2分钟无键鼠操作、无宏录制/执行、无未保存修改、无安全改动保存失败。手动安装也不能跳过数据保护。只安装更高的稳定版本；预发布和便携 ZIP 仅手动下载。

更新包先通过 RSA-SHA256 项目签名与大小/哈希/文件白名单校验，再部署到新版本目录。旧进程正常退出后备份配置，试启动新版；新版就绪后原子切换版本。失败时保留旧版，不强杀进程。后台更新出错会记录安装目录 last-update-error.log；卡住时请检查进程，不要删除配置。

更新协议1拒绝配置格式迁移和启动器协议升级，需另行发布兼容迁移实现或手动运行新安装程序。版本化更新器随签名载荷升级；固定启动入口由安装程序更新。配置备份不自动覆盖用户新数据，旧版本不会自动删除。

项目更新签名不是 Windows Authenticode 代码签名。本软件当前未持有已验证发布者证书，系统可能提示或阻止运行；不要关闭系统安全防护。仅从项目仓库的 Release 下载，核对 SHA256SUMS.txt。

构建安装包：先安装 Inno Setup 7，再执行 Tools/Build-Installer.ps1，传入源码仓库之外的 DPAPI 签名密钥路径；仅发布输出中的 LeiyunLite-* 和 SHA256SUMS.txt，不发布工具、安装器测试版或私钥。私钥只对创建它的 Windows 账户可解密，应另行规划离线备份；丢失密钥后不能继续签发旧安装版信任的更新。

升级本身不改变设备设置。v1.2.1 在已验证的 SE 随附接收器上开放旋转应用，点击应用才写入；范围和实机限制见 [旋转验证](ROTATION-VALIDATION.md)。v1.2.8 验证并开放同一 SE 设备的 00DE 有线旋转控制接口；必须满足设备版本、报告长度与接口用途并成功实时读回，其他接口禁写。设备识别不代表所有控制都可用。宏录制时不要输入密码。

## 测试边界

当前修复验证与范围见 [v1.3.0 发布说明](RELEASE-v1.3.0.md)。此前 [v1.2.4 发布说明](RELEASE-v1.2.4.md)保留为历史记录。安装场景覆盖当前用户安装/快捷方式/卸载登记、重复安装、运行占用、非空目录拒绝和卸载保留日常数据；使用独立 Test AppId，不替换日常安装。

安装测试使用独立Test AppId，不运行主程序、不迁移日常自启动、不执行个人数据清除分支。更高版本的真实自动安装闭环仍需在后续版本发布后验收；下载层沿用已验证的GitHub链路，签名部署已使用本地签名样本测试。标准非管理员账户、Windows11、真正断电/磁盘耗尽、系统安全软件拦截及日常账户的首次迁移仍需额外验收。测试不代表这些场景已经实测。

配置备份位于个人数据目录的 UpdateBackups。卸载默认保留该目录；交互卸载中明确选择清除个人数据时才删除宏、偏好、相关注册表设置及备份。静默卸载始终保留个人数据。
