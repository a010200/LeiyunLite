# v1.2.8 发布说明

2026-10-06。版本 v1.2.8，程序集 v1.2.8.0。维护者已授权正式发布；Motion 未完成项不阻塞本次 Release，后续修复进入 v1.2.9。

## 更新内容

- 优化按钮、开关、下拉面板和侧边页面的弹性交互，让界面操作更自然顺滑。
- 改善右侧面板与录制体验，修复弹层交互问题并加入录制前 3→2→1 倒计时提示。
- 完善 Viper V3 Pro SE 有线旋转校正，修复有线或充电连接下重启后角度显示为 0°、无法应用的问题。

## 验证范围

旋转校正仅对已经验证的 1532:00DE/00DF、设备版本字段 0100、91 字节控制接口、正确接口用途开放。必须获取有效实时读回；预览不写硬件，应用保留设备实例复查、读原值、写目标、读回确认和失败恢复。其他身份/接口保持禁写。

前阶段完成受控有线 -9°→-8°→-9° 写入和无线交叉读回。本阶段使用无参数的真实 DesktopApp.Main，完成纯有线、双连接各一次启动和一次重启、预览可应用及撤销，并确认恢复无线后仍为 -9°；本阶段未写鼠标参数，未修改 DPI 或回报率。

提供安装 EXE、便携 ZIP、项目签名更新 ZIP/JSON 与 SHA256SUMS.txt。项目更新签名不是 Windows 发布者代码签名。原日常 EXE、宏与桌面设置保留，普通入口验收产生的自启动临时变化在每次退出后恢复。

定版验证：csc / MSBuild Release x64，桌面27个不同用例（26+受影响UI单项复验）、底层与宏28组、Rotation Fake/UI 8组、Updater本地17组、隔离安装5项及项目签名/载荷/便携/版本与五附件SHA256通过。详细本机证据保存在被Git忽略的 `test-artifacts/release-v1.2.8.md`，不会随重新克隆自动获得。历史专项结果单独标记，不冒称本轮重测。Motion 2.0 最终 A/B 和手感验收尚未补齐；多轮物理鼠标 A/B、高回报率、新游戏、Windows 11 Snap、多显示器/混合缩放和真实线上更新安装闭环仍有未完成项。

维护者授权提交源码、建立 v1.2.8 标签并发布五个正式附件；不替换日常安装，不修改用户宏、设置或硬件参数。线上附件和客户端更新核验单独记录，不能用本地测试替代。
