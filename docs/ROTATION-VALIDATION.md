# v1.2.1 旋转验证范围

## 实现

当前路线使用设备HID feature报告，不调用或分发厂商私有DLL。命令class `0B`，读取 `94`，写入 `14`，载荷 `[01,01,signed-angle-byte]`，TID `1F`；完整响应检查状态、事务、回显、长度及CRC。角度为有符号整数，输入范围−44°～44°。

应用只允许已记录的1532:00DF、设备描述符版本0100和91字节控制接口。每次操作绑定已选择实例并重新枚举确认；不从型号名称、缓存或演示数据获得写入权限。并发操作在同一个客户端中串行处理，不保证其他设备工具同时访问时成功。

## 2026-09-27 实机记录

维护者退出官方Synapse和原来的lite主程序，用独立研究工具完成同一鼠标0/+10/-10各三次手动单程移动。原始输入按同一实例匹配，所有采样过滤/解析失败为0。厂商后台服务和已安装驱动仍在。

| 设置 | 原始位移方向（度） | 平均（度） | 原自动直线性筛选 |
|---|---|---:|---|
| 0° | 7.58 / 8.08 / 11.32 | 8.99 | 0/3通过 |
| +10° | 21.60 / 21.09 / 19.57 | 20.75 | 0/3通过 |
| −10° | 0.82 / 0.59 / 0.33 | 0.58 | 3/3通过 |

正负组平均方向差20.17°，支持设置确实改变Raw Input位移方向。每次末尾角度读回均一致，九次均恢复原值−8°，关闭工具后再次只读确认−8°。用户认可实际效果并批准发布。

研究工具原直线性指标是净位移除以逐包长度和。低计数斜向整数位移会形成阶梯，该指标可能受方向量化偏差和手部抖动共同影响；六条未通过记录保留，不解释为用户必然回拖，也不伪称自动筛选通过。试验未机械固定鼠标朝向和物理距离，不能检验长度增益或精确角度误差。

## 自动验证

覆盖正负编码、越界/未提供实例键/过期实例拒绝、未知设备版本/报告长度拒绝、错误响应、无效果ACK、写入后抛异常、读回丢失、恢复失败；未确认的目标状态不会显示成功。Raw Input工具另测接口类后缀归一化、实例/集合隔离、32/64位布局及短包拒绝。
