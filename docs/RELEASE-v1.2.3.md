# 雷云lite v1.2.3

本轮针对按住重复宏在 1ms 延迟时松开绑定键仍有收尾粘滞，以及右键开镜、Shift 与中键组合时偶发不触发的问题。宏文件中的 1ms 数值没有改为 10ms；本版不会替换用户的日常安装或旧版备份。

## 下载

- 安装版：`LeiyunLite-v1.2.3-Setup-x64.exe`。
- 便携版：`LeiyunLite-v1.2.3-win-x64.zip`，完整解压后运行 `LeiyunLite.Desktop.exe`。
- 安装版更新附件：`LeiyunLite-v1.2.3-update-x64.zip` 与 `LeiyunLite-v1.2.3-update.json`。
- 完整性校验：`SHA256SUMS.txt`。

安装前请先保存宏草稿并从托盘正常退出旧实例。便携版不会自动执行安装更新。项目更新签名不是 Windows 发布者代码签名。

## 修改

- 显式 1ms 等待不再追赶系统暂停期间错过的时间，避免恢复后向目标连续突发提交动作；宏配置和每步等待值保持不变。
- 无修饰键的鼠标绑定不再因同时按住 Shift/Ctrl/Alt/Win 而失配；如果存在显式修饰键绑定，优先匹配更具体的组合。松开无关按键不停止正在按住的宏。
- 取消重复宏时，在模拟按下前复查取消状态，并在输入钩子拦截本轮迟到的模拟按下；模拟抬起与下一轮输入保持放行。
- 对本轮用过的鼠标键补发最终抬起，避免目标停留在按下状态；内存输入时序同时记录左键按下与抬起的提交/放行计数。

## 验证与边界

- 桌面/核心测试 27/27、旧功能与宏回归 33/33、更新器测试 17/17、隔离安装场景 5/5 通过；两条桌面构建路径通过。
- 1ms 宏核心回归包含防突发、右键＋Shift＋中键触发、无关右键松开不终止宏，以及中键松开后的左键配对和最终抬起；同一停止时序重复运行 20 轮通过。
- 用户在其游戏中试用本轮最终候选后反馈效果良好。该反馈并非覆盖全部游戏、鼠标、权限或输入方式的兼容性证明；Windows 用户态 `SendInput` 不保证所有游戏接受，输入钩子也无法撤回游戏已处理的事件。
