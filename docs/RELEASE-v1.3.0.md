# v1.3.0 — 性能调节与控制接口识别（2026-10-07）

- 优化 DPI 与回报率调节流程，兼容设备实时验证通过后可直接应用设置。
- 精简设备页性能信息显示，保留离散 DPI 输入限制和失败反馈。
- 改进部分雷蛇鼠标的自动控制接口识别，提升性能参数读取的稳定性。

提供安装版、便携版、项目签名更新包和 SHA256 校验文件，见 [v1.3.0 下载](https://github.com/a010200/LeiyunLite/releases/tag/v1.3.0)。产品版本 1.3.0，程序集版本 1.3.0.0；更新签名不等于 Windows 发布者代码签名。

## 兼容范围

保留设备实例、完整描述符与逐能力实时读取校验，写前读取、写后读回和失败恢复。共用控制接口解析器优先既有接口形状，仅对审计过的既有型号扩展只读候选；唯一合法响应才能取得写入权限，多个响应时暂停写入，接口拓扑改变后重新验证。

固定 117 项能力表和 4 项补充配置保持，共 121 有效配置、123 设备身份。这些是静态映射，不代表所有型号均已实测；DA V4、Viper V4、Naga V3 未完成本项目本机硬件验收。没有新增 PID、驱动或运行时第三方依赖。旋转仍仅限既有 00DE/00DF 精确描述符白名单；宏的 WhileHeld、1ms 调度、停止拦截和最终抬起，以及更新验签与回滚保护保持。

## 验证范围与边界

2026-10-06 最终候选通过兼容性 47 项、生成器 12 项及零差异、桌面 27 项、底层与宏 28 项，并完成 csc 与 MSBuild 两条构建。同轮 UI 53/38 项、旋转 Fake/UI 8 项、更新器短长路径各 17 项和路径预算 3 项通过；这些同轮证据不冒称均在正式发布时重跑。2026-10-07 发布从同一已核对源码重新封装，并执行包签名、载荷、版本、哈希及隔离安装验证。

最终候选 SE 无线只读复验为 800 DPI / 500 Hz / 94% / −9°；当轮两次采样 GET10、SET0，日常程序退出后旋转复验通过。00DE 本轮缺席。先前获授权的 DPI/回报率往返属于独立历史验证，发布阶段不重复硬件写入。

Win11 原生 Snap/Win+Z、多屏、Motion 最终 A/B、B4 与手感、新型号与高回报率游戏等仍未完整实机验收。隔离安装采用独立 Test AppId，不激活或替换日常安装；下载验签与真实安装启动是不同验收范围。
