# LeiyunLite v1.2.4

本版修复已确认的七项问题，保持 v1.2.3 的宏时序与设备支持范围，不新增型号写入能力。

## 更新内容

- 回报率探测：每次设备 Probe 只发送一次请求；无法确认时显示未知，下一轮刷新重试，不在同一会话中接受重复请求的迟到回包。
- 硬件缓存：拒绝非法电量、DPI、回报率和损坏的 DPI Stage 组合，未知数据不显示为有效读数。
- 设置恢复：损坏或无法读取的 `desktop.xml` 使用内存默认值启动，不自动覆盖原文件；继续禁止 DTD 和外部实体。
- 版本校验：拒绝版本字符串首尾空白和末尾换行，保留正式版与预览版排序规则。
- 宏界面：语言切换等页面重建保留当前选择的宏及子页面，不自动保存草稿或改变绑定、执行状态。
- 旋转解码：非法偏移量安全返回失败，不因整数溢出抛出越界异常。
- 更新路径：缩短内部临时名称；安装路径超过安全预算时，在开始 Stage 之前明确拒绝，而不是事务中途失败。签名、更新包格式和回滚流程保持不变。

## 验证与边界

修复针对性验证 80/80（含宏核心 13/13）；发布回归 Desktop/core 27/27、旧功能与宏回归 33/33、更新器短路径 17/17、原长路径 17/17、额外路径预算 3/3、隔离安装 5/5。两条主程序构建路径通过。

旧缓存回归样本补齐了“电量已知”标记，并加强合法缓存字段断言；没有放宽产品校验。原生输入测试曾因测试窗口未获前台而安全中止，随后在独立前台测试窗口下复测通过，保留了注入前的前台检查。安装版、便携版和签名载荷版本、内容与 SHA256 均核对；项目公钥验签通过。

支持设备 Viper V3 Pro SE 接收器（00DF / 0100 / 91 byte）只读查询 5 轮通过：电量、DPI、回报率、旋转均能读取，25 次 GET、0 次 SET。本轮没有执行真实硬件写入，也不扩大设备白名单、PID 能力或实例写入范围。TID 0x1F、90/91 byte 布局及 DPI / Polling / Rotation 命令保持不变。

这些结果不是所有型号、Windows 11 或游戏/反作弊环境的兼容保证。宏仍是软件级功能，不写入板载内存，退出程序后不生效。
