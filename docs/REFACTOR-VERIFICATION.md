## 自动检查覆盖

1. 报文头、长度、Report ID、校验和、回报率编码。
2. 90 字节 HID 电量、充电、DPI 档位、回报率响应解析。
3. 91 字节 HID 对应解析。
4. 首个事务 ID 失败后的尝试顺序；DPI 档位查询失败后的单独 DPI 查询。
5. 正常、休眠、唤醒、拔出状态和历史值保留。
6. 无历史电量时的原版兜底值，以及完全无设备的状态。
7. 无响应、短报文、拒绝状态不会被当作成功操作。
8. 90 字节模拟设备的 DPI 档位、DPI 值、回报率写入。
9. 91 字节模拟设备的相同写入。
10. 前一个 HID 接口拒绝请求后继续访问后续接口。
11. 不同设备客户端实例不共享内存缓存。
12. 设置、硬件缓存、开机自启命令保存与读回；无效设置回退；自启命令路径引号与更新。
13. DPI 监控第一次读取不触发变更、真实变更触发、相同值不重复触发、停止后不继续轮询。
14. 正常、休眠、低电量、充电、断开界面；低电量标志与重置；刷新频率、托盘菜单、偏好设置同步；关闭窗口转托盘；资源释放。
15. 界面 DPI/回报率操作能到达模拟客户端，并更新按钮状态。
16. 静默自启隐藏主窗口；显式设置后允许显示窗口。
17. 三个 OSD 样式渲染，以及不激活、鼠标穿透的窗口标志。
18. 原版报文和托盘像素对照。
19. 可选的真实设备读取与原生界面生命周期检查。

## 验证边界

- 真机测试仅发送读取状态的 HID 查询，没有改变实际鼠标 DPI 或回报率。参数写入的报文、调用链和成功/失败处理通过模拟设备检查。
- 没有让用户实际拔插接收器、连接充电线或等待鼠标休眠；这些转换通过模拟状态覆盖。
- 没有进行全屏游戏、不同显示器缩放比例、连续数小时运行或多型号兼容性测试；OSD 标志正确不代表所有游戏场景已验证。
- 回报率未知是这台设备在原版上的既有结果。原版探针仅屏蔽了缓存写注册表的调用，通信和解析逻辑未改动。
- 休眠无缓存默认 50%、DPI 写入失败时的乐观界面回退等原有行为仍保留，详见架构说明。
- 设置测试只使用随机测试注册表子项；自启测试使用该测试子项中的 `Run`，没有修改系统实际 Run 项。测试结束后已删除本次生成的测试子项。

## 复验

```cmd
build.bat -Test
build.bat -Test -Hardware
```

普通测试包含 17 组；加 `-Hardware` 包含 18 组。提供从原版源码编译出的程序集，可增加原版对照组：

```cmd
build.bat -Test -Hardware -BaselineAssembly "完整路径\Original.dll"
```

本次结果日志和测试截图还保存在 `bin/Tests/artifacts/`。该目录属于可重新生成的构建产物，不提交到 Git。
