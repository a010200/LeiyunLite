# 雷云lite v1.2.0

本版在 v1.1.0 上增加安装程序和签名自动更新，不改变 DPI、宏和设备控制范围。

## 选择下载

- **安装版**：`LeiyunLite-v1.2.0-Setup-x64.exe`。默认安装到当前用户目录，提供快捷方式和卸载入口，支持后续版本应用内安装更新。
- **便携版**：`LeiyunLite-v1.2.0-win-x64.zip`。完整解压后运行 `LeiyunLite.Desktop.exe`，无需安装；升级时退出旧版并手动解压新版。
- `update-x64.zip`、`update.json` 供更新器使用，不能代替便携版。`SHA256SUMS.txt` 用于校验全部分发附件。
- GitHub 自动生成的 `Source code` 是代码，不是预编译程序。

运行要求：Windows 10/11 x64、.NET Framework 4.8。安装器不静默安装系统组件，不重启 Windows。

## 从 v1.1.0 / R3 / R4 / R5 升级

先保存宏草稿、停止录制和播放，再从托盘退出旧版；手动运行一次安装程序。旧便携版不会自动转换成安装版。宏、绑定与偏好沿用原存储位置，卸载默认保留数据。以后使用安装生成的快捷方式，不直接运行版本子目录中的 EXE。

## 自动更新

自动检查默认开启；自动下载与空闲安装默认关闭。启用空闲安装后，仅在至少2分钟无键鼠输入，且没有录制、运行中宏、未保存修改或解绑保存失败时升级。手动安装同样遵守保护条件。

更新包通过项目签名、大小、SHA256、文件名单和路径校验；拒绝降级、未知启动协议和不支持的配置迁移。旧进程正常退出后备份配置，试启动新版并等待健康确认；成功切换，失败保留旧版本。只重启雷云lite，不重启电脑，不强杀正在使用的进程。

签名更新从本版开始支持；需要后续更高版本 Release 才能完成用户日常安装的实际升级验收。便携版和预发布包仅手动下载，不自动执行。

## 验证与限制

已通过24组桌面/核心、26组回归、17组更新器测试、5项隔离安装场景及两条构建路径。测试覆盖签名与包篡改拒绝、并发锁、配置备份、进程健康握手与失败恢复。

安装测试使用独立 AppId，没有替换日常安装；标准非管理员账户、Windows11、真实断电/磁盘耗尽和个人数据主动清除仍需额外验收。旋转仍仅预览，不保证全系列设备控制可用。

程序没有 Windows Authenticode 发布者证书，可能出现安全提示。项目更新签名不等于 Windows 代码签名；不要关闭系统防护。

后续每完成一轮修复，版本第三位加1，即使不上传。当前发布 v1.2.0，下一轮修复 v1.2.1。每次发布同时提供安装EXE、便携ZIP、签名更新附件与校验文件，详见[版本规则](VERSIONING.md)。
