# 雷云lite v1.2.1

这是我在独立仓库中发布的首个版本，后续由 a010200 继续维护。代码从当前 v1.2.1 快照开始记录，不导入旧仓库提交历史；保留已有代码的 MIT 许可证和来源说明。

本版接通 SE 随附接收器的真实旋转设置：拖动预览、点击应用、设备读回确认，失败时尝试恢复原角度。完成实体鼠标对照并确认效果后，我将这版作为后续迭代的基线。此次迁移沿用已验证的 v1.2.1 原始发布附件，程序功能、版本和更新地址不变。

## 下载

- 安装版：`LeiyunLite-v1.2.1-Setup-x64.exe`，当前用户安装，支持签名更新。
- 便携版：`LeiyunLite-v1.2.1-win-x64.zip`，完整解压后运行 `LeiyunLite.Desktop.exe`。
- 更新附件：`LeiyunLite-v1.2.1-update-x64.zip` 和 `LeiyunLite-v1.2.1-update.json`，供安装版更新器使用。
- 校验：`SHA256SUMS.txt`。项目更新签名不等于 Windows 发布者代码签名。

## 支持范围

仅 1532:00DF（Viper V3 Pro SE 随附接收器）、HID 设备版本0100、91字节控制接口开放旋转写入。0100 来自设备描述符，并非独立查询的固件版本。00DE 有线、Viper V3 Pro 和其他版本保持禁用。

设备当前角度与待应用值分别显示；输入整数角度或拖动后点击应用。未点击时不修改设备。“撤销预览”回到最近设备读数。校准向导自动填入可用读回值，仍基于系统指针轨迹提供建议。

每次写入先读原值，再写入与读回。实例变化、格式错误或初始读取失败时拒绝写入。发送后出现异常、读回不符或未确认时尝试恢复原值；恢复不确认时提示用户检查设备，不伪报成功。

## 验证及限制

发布验证包括26组桌面/核心、26组既有回归、17组更新器和5项隔离安装场景，以及编译器和MSBuild两条构建路径。隔离安装使用测试AppId，不覆盖日常软件或配置。

官方主程序退出后的三组实机Raw Input平均方向为8.99°、20.75°、0.58°（设置0/+10/-10），正负组相差20.17°，九次角度读回与恢复一致。原始自动直线性筛选有六次未通过，作为手动对照证据保留，不改称自动验收全通过。详情见[旋转验证](ROTATION-VALIDATION.md)。

测试环境仍安装并运行厂商后台服务/驱动；不证明无官方驱动也能使用。重插、休眠、游戏/反作弊、其他连接和边界角度未完成实机验收。DPI/回报率维持原有实验性兼容范围，不因旋转试验而宣称全面验证。

升级过程不自动设置旋转角，不复制研究日志或私人配置。v1.2.0及更早版本在旧仓库和本地档案保留；本公开仓库从v1.2.1开始，不提供此前版本的标签与发布。
