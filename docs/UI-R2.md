# 雷云lite v1.0 · UI R2

## 启动

先从托盘退出旧版，再运行 `LeiyunLite.Desktop.exe`。需要 Windows 10/11 x64、.NET Framework 4.8。软件没有代码签名；请核对来源，不要关闭系统安全防护。

`Preview.cmd` / `LeiyunLite.Desktop.exe --demo` 是安全预览：使用模拟设备，不读写鼠标、不执行宏输入或命令、不保存设置。演示中的电量不是实机读数。

## 本轮完成的调整

- 统一黑夜/白天主题，即时切换，保留宏草稿。夜间主背景 `#141414`、边框与侧栏 `#040404`；白天主背景 `#F2F2F2`、卡片白色、文字 `#1B1B1B`。强调色始终为 `#44D62C`，绿按钮使用深色文字。
- 所有开关采用独立动画状态：210 ms 滑动、小幅回弹、140 ms 轨道变色，按压轻微伸缩。快速反向替换正在运行的动画，状态操作不等待动画。系统关闭动画或开启“减少动画”时取消动效；键盘焦点保留，鼠标点击不再出现点状焦点框。
- 标题栏三个操作改成同尺寸矢量图标；最大化后显示还原图标。保留窗口拖动、缩放和标题栏双击行为。
- 删除“你的设备”和“宏与绑定”标题下的两条副标题，不改变标题内容。
- 托盘图标统一为绿色圆盘 / 黑色 L，断开时灰色；16/20 px 使用简化图形，避免塞入小号电量数字。
- 托盘右键：打开主界面、宏与绑定、设置、暂停/恢复宏绑定、停止所有宏、退出。暂停只阻止新触发；停止是独立动作，紧急停止仍为 Ctrl+Shift+F12。
- 托盘单击：型号、电量、充电/连接状态、最近读数或缓存标识、刷新和打开按钮。双击直接打开窗口；单击等待系统双击判定时间，避免双击时闪出卡片。左右弹层互斥，Esc/失焦关闭，方向键和 Enter 可操作。
- 托盘弹层采用同主题、圆角、细边框与短回弹；弹窗位置按实际窗口尺寸和屏幕工作区约束。低电量和连接通知采用同主题、非激活小卡片，5 秒后消失。
- 设置文案改为“开机自启动”。新增主题、托盘动画、低电量阈值 10/15/20%、设备连接/断开提醒。保留语言、刷新间隔、启动时显示窗口、关闭到托盘、减少动画。
- 新版完全不再创建或显示 DPI 浮窗，移除所有浮窗和托盘图标样式选项。DPI 监测和主页面同步继续工作。旧版 WinForms 文件保留用于历史兼容回归，不从新版入口运行；不删除用户旧配置。

## 宏页面的用法

1. 顶部新建/选择宏；“更多”中重命名、复制或删除。
2. “我的宏”：左侧选择动作，中间显示动作序列，右侧修改属性。窄窗口使用属性抽屉；已有宽屏编辑保持可见直到完成，避免缩放窗口时丢失输入。
3. 动作插入到选中行之后，支持拖动和上/下移动。循环成对添加并缩进显示；移动、删除循环标记时整组处理。参数修改后点击“完成”，或直接“保存并应用”；无效参数会阻止保存并提示。
4. “按键绑定”：独立表格显示触发键、执行宏、方式、是否拦截、启用状态。可选择键盘组合键、鼠标按键、滚轮方向；滚轮不能使用“按住重复”。
5. 草稿切页不丢失，退出前确认未保存内容。保存后才修改有效宏配置，XML 格式沿用旧版。试运行前有警示及 3 秒切换目标窗口时间。没有新增录制和 AI 模板。

宏属于程序后台运行的软件宏，不是写入鼠标板载内存。退出、停止或执行异常时，原有引擎负责释放宏持有的输入。

## 验证结果与边界

- 8 组桌面测试：设备能力与读回校验、旋转数学/校准、设置读写，以及真实 WPF 窗口渲染/交互断言。
- R2 增补断言：两种主题、已有画刷更新、初始开关状态、快速反向/动画收尾/减少动画、失败回滚、移除 OSD 实例、宏编辑/待提交属性保留与校验、成对循环插入/移动/删除、宽窄布局、绑定、托盘弹层互斥/重复开关、实际 HWND 工作区边界、非激活通知、16/20/24/32 px 图标。
- 26 组底层兼容测试：宏动作顺序、释放输入、绑定路由、XML 持久化、HID 模拟读写、DPI 监测、隔离窗口真实 SendInput、专用临时注册表读写等。旧 OSD 测试仅覆盖保留的旧版代码，不代表新版仍有该功能。
- 本轮未向真实鼠标写入设置。不同实体显示器的混合缩放、任务栏自动隐藏和实际托盘单双击手感，仍建议在你的使用环境中体验确认；不能用截图替代这些实机体验。
- **旋转仍只有模型预览和校准测量，不能改变系统光标；在线更新仍未配置。** 没有加入猜测的硬件指令，也没有接入原作者发布源。
- 原 v1.0 EXE、portable ZIP 和首轮 Fluent Preview EXE 的 SHA-256 均核对保持不变。

## 构建与复测

```powershell
.\build-desktop.ps1 -Test
.\build-desktop.ps1 -Regression
```

原生前台输入与注册表隔离测试需要普通桌面权限，在受限执行环境里可能失败。测试仅操作自己的窗口/临时键，不能通过关闭系统安全机制规避权限。

样式、主题与开关分别在 `Desktop/Fluent.xaml`、`Ui.cs`、`ElasticSwitch.cs`；托盘在 `TrayController.cs`；设置在 `ShellWindow.Settings.cs`；宏布局在 `MacroPage.Workspace.cs`，动作/绑定编辑仍由 `MacroPage.cs` 管理。

动画实现参考：[Microsoft HandoffBehavior](https://learn.microsoft.com/en-us/dotnet/api/system.windows.media.animation.handoffbehavior?view=windowsdesktop-9.0)、[Microsoft BackEase](https://learn.microsoft.com/en-us/dotnet/api/system.windows.media.animation.backease?view=windowsdesktop-9.0)。采用 WPF 原生动画，不增加第三方界面框架。
