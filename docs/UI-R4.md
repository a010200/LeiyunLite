# R4 使用与验证

版本：1.0.0-r4 / v1.0 · R4。2026-09-27 本地交付，未上传GitHub。原R3软件包和源码快照保持不变。

## 绑定不再依赖二次保存

“我的宏”仍然是草稿编辑，需要“保存并应用”。“按键绑定”则显示当前生效的配置：

1. 编辑并保存一个包含动作的宏。
2. 从左侧宏库拖到右侧鼠标键位，或点击键位后选择宏。
3. 选择执行方式和是否保留原始输入，确认后立即保存并应用。拖拽到目标本身不立即启用；取消不改变配置。
4. 键位标题变为宏名。点击已分配键位可修改、停用、解除。
5. 解除立即撤销并保存，恢复原始输入，不需要再点“保存并应用”。键盘/组合键在“键盘与高级绑定”中管理。

关闭总开关、停用单个绑定、解绑和删除宏都会停止当前播放（安全策略会停止所有正在播放的宏），取消未执行动作并释放宏按住的键。已发送输入、已启动的进程或命令不能撤回。后续保存宏草稿不会恢复已撤销的绑定。

磁盘保存失败时：解绑在本次运行仍有效，页面提示未持久化及重启风险，并提供“重试保存停用状态”；不要忽略提示。新建/替换/重新启用则先保存，失败时不激活新绑定。被其他宏引用的宏不能直接删除，需先处理引用。

模型为通用七键位示意：左、右、中键，X1/X2侧键，滚轮上/下，不代表特定硬件轮廓或板载映射。未分配的标注是常见系统行为，其他驱动可能改变侧键功能。绑定基于软件全局输入，不能仅限定到图示的那一只鼠标。单个输入仍只匹配一个绑定；高级修改键绑定另行保留。

左键默认保留原始点击。替换左键需明确勾选风险确认，避免失去基本操作。滚轮没有“按住重复”模式。紧急停止仍为Ctrl+Shift+F12，托盘有“停止所有宏”。雷云lite自身窗口内不触发普通绑定。

## 托盘读数

左键卡片保留型号、电量和按钮，增加一行DPI/回报率。打开立即显示缓存，不同步阻塞读取HID；DPI监测事件可更新已打开的卡片。未知项为“—”，休眠/离线时的值仅是最近读数，不是实时USB频率测量。

## 在线更新的范围

仅手动访问 `https://api.github.com/repos/a010200/LeiyunLite/releases?per_page=100`；不连接原作者更新源，也不自动在后台轮询。默认包含预发布版本，可切换仅正式版并保存偏好。

- 标签支持 `v主.次.补丁-r数字` 和正式版本；按数字比较，r10大于r3；不降级，不使用草稿。
- 仅接收严格匹配版本的 `LeiyunLite-v版本-win-x64.zip`。不把GitHub自动源码附件当成软件。
- HTTPS下载，限制跳转到GitHub发布资产域名；限制附件大小100MiB、检查响应长度，支持取消与超时。
- 要求有效的GitHub SHA256摘要或 `SHA256SUMS.txt`；两者都有时必须一致。校验通过才将临时文件发布为ZIP；失败清理该次临时下载。
- 文件保存到 `%LOCALAPPDATA%\LeiyunLite\Downloads\版本-唯一编号\`，不覆盖旧文件；只提供打开下载位置和发布页。
- 不解压、不执行、不自动安装、不替换软件、不重启，不宣称具备代码签名。SHA256不是发布者身份认证或代码安全保证。

发布者以后须使用上述标签和文件名，并上传对应校验清单。当前公开版本R3比R4旧，R4检查时没有新版本是正常结果。网络错误与“没有新版本”分开提示。

## 验证记录

- Framework编译器与MSBuild Release两种路径构建。
- 17组桌面/核心测试、26组旧版回归测试通过；未传入Hardware参数，不操作真实鼠标设置。
- 专项复现：解绑前滚轮触发、宏按住测试键；解绑后停止和释放；1000次滚轮输入不再触发/拦截；XML重新读取无绑定；保存旧草稿不复活绑定。
- 磁盘失败：运行态保持撤销、保存失败明确标记、新绑定不激活、重试保存恢复持久化。
- 并发替换：输入路由并发运行，撤销返回后10000次输入不能启动旧绑定。
- 交互：实际WPF Drop路由事件、确认/取消、默认功能恢复、左键风险保护；黑夜/白天、窄窗口可滚动布局截图。
- 更新：版本排序/频道/不降级/错误仓库与架构过滤、超限/摘要错误/取消测试；真实API确认R4不降级，测试基线r2真实下载R3并校验ZIP `2f8c40def3342517e5ecbb9100d2164daeff184950ea6b0e80613538b2c2f2eb`。该附件没有被执行或安装。

这些验证不等于真实多设备、目标游戏、多显示器或实际物理拖拽体验已全面验收。用户R3进程和配置未被测试接管。真实旋转校正仍未实现，本轮未改。

## 手动升级与回退

1. 可先备份 `%LOCALAPPDATA%\LeiyunLite` 配置目录，尤其macros.xml与desktop.xml。
2. 从R3托盘退出，避免旧实例仍在运行；解压R4至独立目录，运行LeiyunLite.Desktop.exe，确认标题R4。
3. 用无风险动作绑定滚轮，确认可触发，再解除，不点保存，确认滚轮恢复正常；重启R4再检查。
4. 自启动路径更换后，在设置重新启用“开机自启动”。R4不会擅自改写旧路径。
5. 需要回退时退出R4，再启动保留的R3；R3的旧绑定草稿逻辑仍存在。软件回退不自动回滚用户配置。

## 代码定位

- Macros/MacroController.cs：原子配置提交、立即撤销、草稿隔离与失败状态。
- Macros/BindingRouter.cs：输入路由替换与取消；MacroStore.cs：本地持久化接口。
- Desktop/MacroPage.Bindings.cs / MouseBindingMap.cs：宏库与鼠标键位交互。
- Desktop/ShellWindow.Bindings.cs：界面草稿与运行配置同步、演示隔离。
- Desktop/TrayController.cs：非阻塞托盘读数展示。
- Desktop/ReleaseUpdateService.cs / UpdatePage.cs：受限GitHub下载服务与用户操作页。
- Tests/DesktopTests.R4.cs：安全解绑、失败/并发、更新及界面测试。
